## Overview

This course builds one small MCP server across nine short lessons: a tool, a resource, and a prompt, then inputs and results, debugging with MCP Inspector, and the capabilities worth knowing about next.

## Outline

- [learn-mcp/what-is-mcp] - What MCP is, the three roles, and what a server exposes
- [learn-mcp/transports] - stdio vs. Streamable HTTP, and registering a server with your assistant
- [learn-mcp/your-first-server] - Build a server with one tool
- [learn-mcp/adding-a-resource] - Add a resource
- [learn-mcp/adding-a-prompt] - Add a prompt
- [learn-mcp/asking-for-input] - A tool that asks the user a question mid-call
- [learn-mcp/inputs-and-results] - Declaring arguments with Zod and shaping a result
- [learn-mcp/debugging-with-inspector] - Driving MCP Inspector and reading the wire
- [learn-mcp/going-further] - Serving over HTTP, progress, subscriptions, and authorization

## Prerequisites

- ✏️ Node.js installed.
- ✏️ VS Code with GitHub Copilot or Claude Code.
